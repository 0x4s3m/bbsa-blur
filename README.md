# BBSA Blur

## Install (Chrome / Edge / Brave)

1. Download and unzip `bbsa-blur.zip`.
2. Open `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the `bbsa-blur` folder.
5. Open `bugbounty.sa` — the page loads blurred. Hover an element to reveal it.
